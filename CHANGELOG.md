# История версий

## v1.0.0 — Первый публичный релиз (тестирование)

- **Прямая загрузка в `/photounlim` с компьютера** через внутренний web-API `models-v2` (`mpfs/store`) по данным входа из браузера (`cookies.json`), без пароля, телефона и эмуляторов.
- **Строго только чтение папки на ПК:** исходные файлы и подпапки никогда не удаляются, не перемещаются и не изменяются. Симлинки и NTFS-junction пропускаются.
- **Умный фильтр фото и видео:** загружаются поддерживаемые форматы (`JPG`, `PNG`, `HEIC`, `WebP`, `GIF`, `BMP`, `TIFF`, `MP4`, `MOV`, `M4V`, `3GP`, `MKV`, `AVI`, `WebM`, `MTS`, `MPG`, `WMV`, `FLV`) с проверкой заголовков (magic bytes). RAW-файлы (`.dng`, `.cr2`, `.nef`, `.arw` и др.) и документы пропускаются с отчётом, чтобы не расходовать обычное место Диска.
- **Тройная защита от дубликатов:** локальная БД (`upload_state.db`) и дедупликация копий по `(size, md5)` с координацией параллельных потоков, предварительная индексация `/photounlim` (`mpfs/list`), обработка `hardlink` и HTTP 409 code 72.
- **Докачка больших видео:** чанковая отправка по RFC 9110 (`Content-Range`) с автоматическим восстановлением после обрыва связи (`HEAD` → `Content-Length`).
- **Защита основной квоты (Quota Guard):** проверка подписки Яндекс 360 и лимита файла до старта, контроль `storage_type == "photounlim"` и автоматическая остановка при росте обычного занятого места.
- **Режим наблюдения (`--watch` / галочка в Web UI):** автоматическая подгрузка новых фото и видео из папки.
- **Локальный веб-интерфейс (`http://127.0.0.1:8001`):** работает рядом с `yadisk_backup` (`8000`), защищён localhost-проверкой, CSRF-токеном и CSP, умеет экспортировать таблицу в CSV и собирать безопасный архив диагностики «Отчёт для поддержки» без секретов и кук.
- **Запуск в один клик без ручной установки Python:** `webui.bat` (Windows), `webui.command` (macOS), `webui.sh` (Linux) с проверкой SHA-256 официального `uv 0.13.4`.
